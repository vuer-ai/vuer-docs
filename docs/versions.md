# Versions and previous builds

Use the Python version menu at the top of the page to select a release. Each of the 149 historical tags has its own documentation branch, built from that release's original source.

## Original documentation

The [previous documentation site](https://vuer-py.readthedocs.io/en/latest/) remains available on Read the Docs. The [build archive](https://vuer-docs-archive.netlify.app/) lists its 117 previously published versions and serves the original pages.

## Downloadable backup

The [September 7, 2026 preservation release](https://github.com/vuer-ai/vuer-docs/releases/tag/docs-preservation-2026-09-07) includes a checksummed backup, restoration script, source references, and public build records.

The downloadable rendered backup is partial: it contains 270 saved files from 73 versions. Files outside that snapshot remain available through the retained Read the Docs site. The build archive uses that original site for missing files, so it is not a fully offline copy.

## Source history

In [the documentation repository](https://github.com/vuer-ai/vuer-docs), `archive/<tag>` preserves each original source snapshot and `docs/<tag>` contains its Dockit documentation. Early releases without a dedicated documentation directory show their original README and a generated API reference.
