# Vuer documentation with DreamLake Dockit

The original `docs/` MyST/Sphinx sources and `src/vuer` Python source are preserved. This standalone site uses `@dreamlake/dockit` 0.2.14; a deterministic converter translates authored pages, navigation directives, local assets and Python API references without importing Vuer or running example servers.

```sh
cd docs-site
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm ci
PYTHON=.venv/bin/python npm run build
npm run preview
```

Build output is `docs-site/dist/client`. Generated pages are disposable: edit the authored Markdown under `docs/`, then rebuild. Python API pages are generated by the pinned `dreamlake-ai/autodoc-py` dependency. The site publishes Markdown twins and `/llms.txt`, uses Pagefind for search, and keeps embedded interactive Vuer scenes.

Production uses `main`; historic `docs/<tag>` branches retain the corresponding upstream source commit with this tooling overlaid. `archive/<tag>` refs preserve unmodified source snapshots. Netlify deploys documentation branches individually. The version selector reads production `/versions.json`, with CORS enabled so historic branch sites always discover newly published versions. Never force-push archival refs.
